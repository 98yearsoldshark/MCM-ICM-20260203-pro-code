# 260130-13:10z-电池-雪崩-恢复

## 背景/问题（以赛题为裁判）

赛题要求建立**连续时间**、有明确机理边界的手机电池模型，输出 SOC(t) 并预测不同场景下 TTE；不能只做离散拟合/黑箱回归。我们因此用“手机功耗 P(t) → 电池电学/热/老化 → SOC(t), V_term(t) → TTE”的闭环作为主线。

本条专用叙事记录一次关键的理论互相纠正：围绕两件事把模型从“看起来合理”推到“数学严密 + 工程可解释”：
- **恒功率负载下的电流雪崩（Avalanche / Death Spiral）**
- **负载解除后的恢复效应（Recovery / Relaxation）**

## 结论先行（可直接复用到后续实现的“理论约束”）

1) “雪崩”不是玄学：它是**恒功率负载（CPL）+ 电池内阻/极化**耦合产生的**可行域边界**问题。工程表述应写为：
> 系统进入无稳态/不可满足功率需求区域，电压快速塌陷并触发关机/保护。

2) “恢复效应”不是 SOC 回升：恢复的是**端电压与电压裕量（headroom）**，本质来自**极化/扩散松弛**；SOC_true 仍单调下降。

3) “OCV 方程是否需要统一解析式”：赛题不要求“优雅闭式”，只要求连续时间机理。**最稳、最可校准、最不翻车**的做法是：
- 计算上以 **查表/分段线性（或单调样条）**作为 OCV(SOC) 的“工作模型”
- 论文上可用一个“统一的平滑近似式”做点缀，但必须保证**有界、单调、无奇点**，并声明它是近似表达而非硬物理定律

## 雪崩效应：严格推导 + 工程解释

### 1) 关键澄清：不要混淆两种“电阻”

- 负载等效电阻 R_load：CPU/系统侧可变（为了维持功率它会变化）
- 电池内阻 R_internal（常用 R0 表示）：电池内部的欧姆阻抗与极化阻抗（可随温度/SOC变化，但不会“按 CPU 意愿变化”）

“雪崩”源自电池端：电流增大时，固定（或缓慢变化）的 R_internal 使压降与损耗急剧放大。

### 2) 最小闭环方程（Model-1 的骨架）

电池端电压：
```
V_term = OCV(SOC) - I*R0 - V_p
```

恒功率负载（忽略效率时）：
```
P = V_term * I
```

联立得到关于 I 的二次方程（把 V_p 合并到“等效开路电压”里）：
```
R0 I^2 - (OCV - V_p) I + P = 0
```

判别式：
```
Δ = (OCV - V_p)^2 - 4 R0 P
```

若 Δ < 0，则不存在实数解：意味着在当前 SOC/温度/极化状态下，电池无法提供所需功率——这就是“不可满足功率需求区域”。

### 3) 物理解释（避免“电流趋于无穷大”的不严谨说法）

数学上接近边界时会呈现强非线性；工程上真实系统会被以下机制截断：
- 电源管理限流/保护
- 热失控风险触发降频
- 电压跌破系统工作阈值触发关机

因此论文表述应强调：**进入不可行域后，系统会快速塌陷并被保护/关机策略终止**。

### 4) DC-DC 效率 η：是加速剂，不是根因

更真实的功率闭合应写为：
```
P_batt = P_load / η(I, V_term, T)
```
η 随电流增大往往下降，会使“不可行域”更早出现（Δ 更快变负）。
但即便把 η 取常数，雪崩的“可行域边界”仍然存在，这是它的结构性强点（不靠拍脑袋）。

## 恢复效应：正确叙事（SOC 不回升，电压回升）

### 1) 为什么“逐渐回升”是关键字

电压回升包含两类项：
- 欧姆压降 I*R0：电流下降时几乎瞬时变化
- 极化/扩散电压 V_p：具有时间常数，表现为“逐渐”恢复

### 2) 一阶 RC（Thevenin 1RC）即可写出连续时间恢复

极化电压的最小 ODE：
```
dV_p/dt = I/C1 - V_p/(R1*C1)
```

当负载减小（I 变小）或停止时，V_p 将以时间常数 τ = R1*C1 衰减，V_term 随之回升，电压裕量变大，系统再次回到“可行域”并能继续工作（如果 SOC 仍高于关机策略阈值）。

## OCV(SOC)：分段 vs 统一解析式（建议的最终取舍）

### 我认为更“Z 奖稳健”的做法：计算用分段，论文可点缀统一式

**主张**：以“可校准/可复现/不翻车”为最高优先级。

1) 计算层（推荐）：
- 用开源数据/公开规格拟合 OCV(SOC) 曲线，采用：
  - 分段线性查表（piecewise linear），或
  - 形状保持的单调样条（例如 PCHIP/单调三次 Hermite）
- 约束：单调不减、有界（例如 [V_min, V_max]）、SOC 下界截断（SOC_min）

2) 表达层（可选加分点缀）：
- 给出一个“统一平滑近似式”用于解释“两端陡峭、中间平缓”的形状，但必须满足：
  - 不出现 SOC→0/1 的数学奇点（或显式声明在 SOC_min 处截断）
  - 参数可解释（平台电压、低 SOC 膝点、满电表面电荷松弛项等）
  - 明确写出：这是对查表曲线的光滑化表达，用于论文展示，不是强行替代数据

### 为什么我不建议强行追求“一个公式统一一切”

- 赛题更看重：机理闭环、可验证、能解释场景差异与不确定性。
- 过度追求“优雅闭式”容易引入不物理外推（例如奇点、无界），反而会被评委抓到漏洞。
