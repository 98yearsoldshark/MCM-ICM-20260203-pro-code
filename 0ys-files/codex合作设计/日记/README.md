# 日记文件夹使用规则

本文件夹用于记录“Codex 协作设计”过程中的日记与专题笔记。为保证可追溯、可串联，请遵守以下规则。

## 1) 文件命名（精确到分钟，统一 t/z 标记）

- 统一格式：`YYMMDD-HH:MM<标记>-主题.md`
  - `t`：通用叙事（timeline / time-ordered）
  - `z`：专用叙事（专题 / zhuanti）
  - 示例：
    - 通用：`260130-12:51t-消融实验.md`
    - 专用：`260130-13:10z-电池-雪崩-恢复.md`
- `YYMMDD`：两位年份 + 月 + 日（如 2026-01-30 写作 `260130`）
- `HH:MM`：24 小时制，精确到分钟
- `主题`：尽量用短语，能一眼看懂该条记录的主旨

## 2) 两类叙事：通用叙事（t） vs 专用叙事（z）

### A. 通用叙事（t，时间轴连续）

用途：记录当天推进、决策、实验、改动、结论与下一步等“流水账式”过程。

强制规则：
- **必须与上一条通用叙事紧密衔接**：本条内容从“上一条通用叙事结束的瞬间之后”开始叙事。
- 为了让“结束瞬间”可校验：每篇通用叙事**必须在文末写明结束时间（精确到分钟）**。
- 下一篇通用叙事的文件名时间戳，必须与上一条通用叙事文末的“结束时间”一致（作为衔接点）。

推荐标题写法：
- `YYMMDD-HH:MMt-通用叙事.md`
- 或 `YYMMDD-HH:MMt-通用叙事-子主题.md`

通用叙事模板（建议）：
```md
# 260130-12:45t-通用叙事

- 承接：上一条通用叙事《260130-11:20t-通用叙事》（结束于 260130-12:45）
- 开始：260130-12:45

## 进展
## 决策与理由
## 结果与证据（命令/文件/图）
## 风险与偏差（误差来源）
## 下一步

- 结束：260130-13:10
```

### B. 专用叙事（z，主题优先）

用途：围绕某个现象/概念/方法做结构化说明（例如“雪崩效应实现”“TTE 定义澄清”“校准不可辨识性”）。

规则：
- 按 `YYMMDD-HH:MMz-主题.md` 命名（时间表示记录创建/写作时刻）。
- **不要求**遵守“从上一次日记结束的瞬间之后开始叙事”（可独立成篇）。

专题叙事模板（建议）：
```md
# 260130-12:45z-雪崩效应实现

## 背景/问题
## 机理/推导/直觉
## 实现要点（伪代码/关键公式）
## 结论
## 参考（可选）
```

## 3) 其它约定（建议）

- 统一使用 Markdown；避免把关键结论只写在聊天记录里。
- 尽量写清“输入-假设-方法-输出-结论”，便于复盘与迁移到论文。
- 涉及代码改动时，记录到具体路径（例如 `MCM_Sim/26A/src/...`）与可复现命令（`PYTHONPATH=... python ...`）。
