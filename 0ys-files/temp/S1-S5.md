# Table 2: S1–S5 Scenario Settings
| Scenario               | Typical Behavior                                                                 |
|------------------------|----------------------------------------------------------------------------------|
| S1 Standby/Light       | Use Low brightness or screen off, low throughput, few background apps            |
| S2 Browsing/Social Media | Frequent app switching and loading, multiple background apps active             |
| S3 Video/Live Streaming | Steady load but prolonged usage, large caching                                  |
| S4 Gaming              | High CPU/GPU utilization, elevated temperatures                                  |
| S5 Navigation/Calling  | Frequent cellular switching, constant GPS use, noticeable performance degradation in weak signal areas |
