# Q3（Sensitivity and Assumptions）未来任务打卡清单（面向 Z 奖）

时间：2026-02-01  
对应赛题条目：  
> “Examine how your predictions vary after making changes in your modeling assumptions, parameter values, and fluctuations in usage patterns.”

本清单目标：把 Q3 的证据链做成“评委友好 + 可复现 + 可引用 + 观测锚定”，避免只停留在“我们自己设定的仿真世界”。

---

## 总体检查（必须项）

- [x] **先验来源表（可引用）**：把每个参数先验区间与来源（开放数据/公开规格/文献）整理成一张表（可放正文或附录），并在文中引用。  
  原因：Q3 的敏感性强依赖“先验范围”，没有来源会被质疑结论主观。
- [x] **稳定性复现实验**：对 PRCC/方差分解做“样本数 N / seed 重复数 K” 的稳定性检验，展示排名/占比变化很小。  
  原因：评委会质疑“换个随机种子是不是就变了？”
- [x] **观测锚定图形质量修复（排版+配色+误读修正）**：针对 Q3 三张观测锚定核心图，修复“重叠严重/配色异常/随机项显示 0.0%”等问题，统一使用 Skip Gradient 配色表，并在图中用 “<0.1%” 避免 0.0% 的误读。  
  原因：这类锚定图通常会放在正文，视觉效果与可读性直接影响评审第一印象与可信度。
- [x] **观测锚定（至少 2 张正文图）**：正文至少包含 10（Monsoon α-sweep）与 11（usage×aging 分解）之一，最好两张都放。  
  原因：赛题明确 Data-as-support；观测锚定是冲高奖的重要加分点。
- [x] **Q3 章节合并草稿**：合并 Q3材料中多个 `paper_fragment_zh.md`，形成可直接粘贴进中文论文的“Q3 大段正文”。  
  原因：把图-结论-解释串成统一叙事，减少写作割裂感并方便协作。

  - paper 图不带数字（肉眼难读），但 `other/data.csv` 可读。
- 下一步任务：
  - [x] 生成 “带数字的论文辅助版” 热力图（不一定替换 paper 主图，可放 `other/figure_numbers.png`）。  
    原因：便于团队快速审阅/写作提取结论。
  - [x] 运行 N/K 扩容对照（例如 N=240/600/1000；K=4/8），比较 top5 排名稳定性。

  - [x] 用开放数据/公开资料给先验定界（量级锚定）：已用 AndroWatts（部件能耗占比分位数）+ 电池状态表（SOH 分位数）整理 **先验来源表**（见 Q3-12）。
