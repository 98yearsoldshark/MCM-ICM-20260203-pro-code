# 00 - PyBaMM 是什么（以及对 26A 题有什么用）

PyBaMM（Python Battery Mathematical Modelling）是一个开源的电池 **机理建模 + 数值求解** 框架，核心关注：
- 用常/偏微分方程刻画电池内部（电极/电解液）过程；
- 支持多层次模型（从快到慢、从简单到复杂）；
- 提供统一 API：参数集、实验协议（Experiment）、仿真（Simulation）、求解器（Solver）与结果（Solution）。

## 能做什么（你会用到的部分）

对 MCM 2026A（智能手机电池续航）而言，PyBaMM 可以提供比“能量守恒/SOC 线性模型/ECM”更物理、更可解释的电压响应：
- 给定 **电流 (A)** 或 **功率 (W)** 随时间的负载协议，输出：电压 V(t)、电流 I(t)、功率 P(t)、容量消耗 Q(t) 等；
- 自动处理“放电到截止电压（关机）”这类事件终止；
- 用不同复杂度模型做“快/慢/精度”的折中：
  - SPM / SPMe：快，适合做大量情景/策略扫描；
  - DFN（P2D）：更精细但更慢，适合做少量对照与机理解释；
  - （可选）热/老化：解释低温续航、发热、容量衰减等（论文可作为升级路线）。

## PyBaMM 的输出怎么接入我们的论文叙事

推荐写法（与 `MCM_Sim/26A/src/README.md` 的 Model-0/1/2/3 路线一致）：
- Model-0：功耗 -> SOC -> TTE（最简、可快速扫策略）
- Model-1/2：ECM + 截止电压 + 温度（更贴近真实关机）
- **Model-2.5（可选）**：引入 PyBaMM（SPM/DFN）作为“更机理的电压模型”对照，论证我们简化模型的合理性

注意：PyBaMM 更“重”，不建议把它当成全流程的唯一仿真器；更适合作为：
- 机理对照基准（benchmark）
- 为 ECM/简化模型“提供形状正确的曲线/关系”
- 给论文提供“更有说服力的物理解释”
