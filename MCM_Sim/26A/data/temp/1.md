# MCM 2026 Problem A
## 手机电池耗电建模数据来源与说明文档
本说明文档覆盖：真实数据来源与网址、变量定义、预处理方式、以及最终拼接表（主表）的结构与使用方式。

# 1. 真实数据来源（公开可获取）
数据源A（手机功耗/设备状态）：AndroWatts 数据集（Zenodo）
用途：提供 1000 次移动设备组件刺激测试的聚合指标，包括设备状态（亮度、CPU/GPU频率、WiFi数据量、温度、SOC%等）及各组件/电源轨功耗指标。
网址：https://zenodo.org/records/14314943
DOI：10.5281/zenodo.14314943；许可：CC BY 4.0（Creative Commons Attribution 4.0）

数据源B（锂电循环/老化）：Battery Degradation Datasets (Two Types of Lithium-ion Batteries)（Mendeley Data）
用途：提供两类锂电池的退化数据（Excel），用于提取有效容量 Q、SOH 与 OCV(SOC) 关系，并用于老化敏感性分析。
网址：https://data.mendeley.com/datasets/v8k6bsr6tf/1（镜像：https://data.niaid.nih.gov/resources?id=mendeley_v8k6bsr6tf）
DOI：10.17632/v8k6bsr6tf.1；许可：CC BY 4.0

# 2. 本项目实际使用到的原始文件
（A）AndroWatts：open_data.zip（来自 Zenodo 记录）
使用文件：material/res_test/aggregated.csv（1000 条测试聚合指标）
随附说明：README.txt；material/trace_parser/README.md（列出从 perfetto trace 提取的指标列表）

（B）Mendeley 电池老化数据：Battery Degradation Datasets (Two Types of Lithium-ion Batteries).zip
使用文件：Dataset#3.xlsx、Dataset#5.xlsx；每个工作簿包含 Cell01/Cell02/Cell03 三个 sheet。
表结构：行=Sample #k（代表一次循环/样本）；列=若干电压点（例如“3.5 V”），单元格为该电压点下累计容量（Ah）。

# 3. 数据预处理与特征构造
## 3.1 AndroWatts（手机功耗侧）预处理
1) 读取 aggregated.csv，并将 ID 重命名为 phone_test_id。
2) 单位换算：AVG_SOC_TEMP（m°C）→ temp_c=AVG_SOC_TEMP/1000；BATTERY__PERCENT（%）→ soc0=BATTERY__PERCENT/100。
3) 电流尺度：I_obs_A=BATTERY_DISCHARGE_RATE_UAS×1e-6。该字段来源于 perfetto trace 的聚合导出（trace_parser README）。
4) 合计功耗：P_total_uW = Σ(所有 *_ENERGY_UW 列)。
5) 合计能量代理：E_total_uWh_est = Σ(所有 *_ENERGY_AVG_UWS 列)。该量与 P_total_uW 的比值用于估算测试时长 duration_h_est（近似）。

## 3.2 Mendeley（电池老化侧）预处理
1) 读取 Dataset#3/#5 的 Cell01~Cell03 sheet。识别电压列（形如“x V”）与样本行（Sample #k）。
2) 对每个样本，取最高电压列对应容量作为该样本的满充容量 Q_full_Ah。
3) 对每个 cell，定义 SOH = Q_full_Ah / Q_full_Ah(该cell第1个样本)。
4) 选取 6 个代表性老化档位：new(≈1.00)、slight(≈0.95)、moderate(≈0.90)、aged(≈0.85)、old(≈0.80)、eol(该cell最小SOH)。每档位取 SOH 最接近目标值的样本。
5) 在每个代表样本上拟合 OCV(SOC) 多项式：令 SOC=Q(V)/Q_full_Ah，拟合 V≈c0+c1·SOC+…+c5·SOC^5，输出 ocv_c0~ocv_c5。

## 3.3 拼接与最终主表构造
两数据源不存在可对齐的共同主键，因此采用“场景组合”方式：每条手机功耗测试（1000条）与每个电池老化状态（36个）做笛卡尔积，得到 36,000 行主表。
主键建议使用 (phone_test_id, battery_state_id)。
额外派生列（便于连续时间SOC建模的初始化/近似）：dSOC_dt_est_per_s≈-I_obs_A/Q_eff_C；t_empty_h_est≈soc0/(-dSOC/dt)/3600（常流近似）。

# 4. 最终表（主表）说明
文件名：MCM2026_master_modeling_table.csv
规模：36000 行 × 93 列。
组成：AndroWatts 原始字段（69列）+ 电池状态字段（15列）+ 派生列（若干）。
用途：用于在连续时间模型中将“负载功耗/设备状态”与“电池参数/老化状态”组合，进而积分得到 SOC(t) 并预测电量耗尽时间。

# 5. 变量定义（摘要版）
完整变量字典另存为：MCM2026_data_dictionary.csv（包含每列的单位、说明、来源与预处理）。以下列出建模最常用的关键变量：

|变量|单位|定义/含义|来源|
|---|---|---|---|
|phone_test_id||手机功耗测试编号（AndroWatts aggregated.csv 的 ID 重命名）|AndroWatts|
|battery_state_id||电池状态ID（由数据集/电芯/老化档位组成）|Mendeley(派生)|
|Q_full_Ah|Ah|该电池状态下满充容量（取最高电压列对应容量）|Mendeley(派生)|
|SOH|1|容量健康度=Q_full/Q_full(新电池)|Mendeley(派生)|
|Q_eff_C|C|有效电荷量=Q_full_Ah×3600|Mendeley(派生)|
|soc0|1|初始SOC=BATTERY__PERCENT/100|派生(AndroWatts)|
|temp_c|°C|平均SOC温度：temp_c=AVG_SOC_TEMP/1000（原字段为毫摄氏度）|派生(AndroWatts)|
|I_obs_A|A|观测放电电流：I_obs_A=BATTERY_DISCHARGE_RATE_UAS×1e-6（由字段名推断尺度，作为电流量级使用）|派生(AndroWatts)|
|P_total_uW|µW|各组件平均功率合计：sum(*_ENERGY_UW)|派生(AndroWatts)|
|dSOC_dt_est_per_s|1/s|常流近似下SOC导数：dSOC/dt≈-I_obs_A/Q_eff_C|派生(组合)|
|t_empty_h_est|h|常流近似下到0电时间（小时）|派生(组合)|
|ocv_c0|V|OCV(SOC)多项式系数 c0：V≈c0+c1·SOC+…+c5·SOC^5（五次拟合）|Mendeley(派生)|
|ocv_c1|V|OCV(SOC)多项式系数 c1：V≈c0+c1·SOC+…+c5·SOC^5（五次拟合）|Mendeley(派生)|
|ocv_c2|V|OCV(SOC)多项式系数 c2：V≈c0+c1·SOC+…+c5·SOC^5（五次拟合）|Mendeley(派生)|
|ocv_c3|V|OCV(SOC)多项式系数 c3：V≈c0+c1·SOC+…+c5·SOC^5（五次拟合）|Mendeley(派生)|
|ocv_c4|V|OCV(SOC)多项式系数 c4：V≈c0+c1·SOC+…+c5·SOC^5（五次拟合）|Mendeley(派生)|
|ocv_c5|V|OCV(SOC)多项式系数 c5：V≈c0+c1·SOC+…+c5·SOC^5（五次拟合）|Mendeley(派生)|

# 6. 可复现性说明
主表由两份原始压缩包按固定规则生成：open_data.zip（AndroWatts）与 Battery Degradation Datasets…zip（Mendeley）。规则包括：单位换算、功耗合计、老化档位抽样与 OCV(SOC) 拟合、多表笛卡尔积拼接。
