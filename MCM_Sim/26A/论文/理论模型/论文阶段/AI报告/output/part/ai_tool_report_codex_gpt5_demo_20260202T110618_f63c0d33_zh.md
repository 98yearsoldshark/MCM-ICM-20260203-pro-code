## 2. LLM / 生成式 AI 详细记录

### 2.1 工具 / 模型信息

- 工具 / 模型：OpenAI Codex（基于 GPT-5）
- 版本 / 日期：2026-02-02（示例写法；以队伍真实使用记录为准）
- 使用方式：本地命令行（Codex CLI）+ 访问项目工作区文件
- 用途（本项目）：
  1) 统一术语与叙事口径（TTE、欠压裕量、老化/SOH、使用波动等），输出可直接入论文的段落；
  2) 把“赛题口径”映射为可实现的模块与实验：敏感性（PRCC/Tornado）、假设检验（消融/结构对照）、不确定性分解（总方差/观测锚定）；
  3) 工程实现：脚本入口、输出目录规范、绘图 paper/study 双模式；
  4) 调试与核验：识别统计口径与实现细节导致的偏差，并给出可复现修复方案。

### 2.2 交互日志（展示用示例）

> 注：下述 Query/Output 为“展示用概括”，用于说明 AI 在团队工作流中的角色；最终模型、参数、结论均由队伍独立核验并以可复现实验为准。

#### 日志 1：从赛题文本到“可实现”的建模口径

- 时间：2026-01-30 10:20（示例）
- Query（概括）：
  - 将赛题 Q1/Q2/Q3 的文字要求转成可执行的建模任务清单；
  - 明确输出指标：TTE、欠压风险、解释性分解；
  - 给出“论文写法”的章节结构（更完整、更易审查、更强叙事）。
- Output（概括）：
  - 给出以连续时间机理模型（ODE + 阈值截止事件）为核心的统一框架；
  - 明确 Q3 三条主线：参数敏感性、假设敏感性、使用波动敏感性；
  - 建议“Data-as-support”叙事：公开数据用于锚定量级、校验方向与增强可解释性，而非替代模型推导。
- 核验与修改说明：
  1) 队伍逐条对照赛题原文，删除任何超出题意的扩展要求；  
  2) 对所有指标给出可计算定义（尤其是风险指标“欠压裕量”）；  
  3) 固化可复现约束：每张图必须对应脚本入口与输出路径。

#### 日志 2：Q3 的敏感性与假设——图与实验的“证据链”设计

- 时间：2026-01-31 09:40（示例）
- Query（概括）：
  - Q3 应该输出哪些图，才能覆盖“改变假设/参数/使用波动 → 预测如何变”？
  - 哪些图适合放正文，哪些放附录？
- Output（概括）：
  - 正文主图建议：PRCC 热力图（均值 TTE、欠压裕量）、机制消融、使用波动分布、总方差分解、观测锚定分解（usage×aging×交互×随机）；
  - 附录建议：bootstrap 置信区间、跨电芯稳健性、压缩热图等增强证据；
  - 强调“paper/study”双模式：paper 只保留结论所需信息，study 写清口径、读图方法与局限。
- 核验与修改说明：
  - 在生成图前先固定统一口径（单位、阈值、随机种子策略）并写入文档；
  - 对“图能否回答题面一句话”做逐项核对，删掉与题意弱相关的可视化。

#### 日志 3：调试案例——Bootstrap 置信区间口径修复（避免虚假“稳定”）

- 时间：2026-02-01 15:10（示例）
- Query（概括）：
  - 观测锚定分解的 bootstrap CI 看起来过窄，是否实现有误？
  - 如何在 cluster bootstrap 下保持“重复抽样”的权重信息？
- Output（概括）：
  - 指出常见错误：用布尔 mask/去重索引会把“重复抽样”合并，导致 CI 人为变窄；
  - 建议改用“加权 cluster bootstrap”：对每个 phone_test 的抽样次数做权重加权，重新计算分解占比；
  - 给出实现思路与核验策略（检查权重分布、复现实验种子、对比修复前后 CI）。
- 核验与修改说明：
  - 队伍复现并对比修复前后 CI 宽度与主结论稳定性；
  - 将修复后的结果以 v2 方式另存，避免覆盖旧图，便于人工审阅与追溯。

#### 日志 4：论文片段生成与公式检查（避免排版/符号错误）

- 时间：2026-02-02 09:30（示例）
- Query（概括）：
  - 为 Q3 图 Q3-11a~e 撰写可直接入稿的中文/英文段落；
  - 检查公式与 LaTeX 转义（例如 \% 与下划线）。
- Output（概括）：
  - 提供一段“从图到结论”的叙事模板：先定义口径 → 解释主效应 → 解释交互 → 给稳健性证据；
  - 修复 LaTeX 常见问题（例如把 <code>%</code> 改为 <code>\%</code>、避免错误转义导致不渲染）。
- 核验与修改说明：
  - 队伍逐句对照代码输出的字段含义核验；
  - 对任何可能暗示外部事实/引用的句子进行删改，避免引入不可证伪信息。
