# Q1 材料（图 + 插入片段）

目的：把 Q1（连续时间电池端模型/ECM）相关的**核心论文插图**和**可直接粘贴进论文的上下文片段**放在同一处，便于写作与排版。

使用方式（最小闭环）：
1. 进入某个子文件夹，查看 `figure.png`（论文版、干净图）。
2. 打开同目录的 `paper_fragment_zh.md`，把其中“插图位置 + 图题 + 中文解读段落”粘贴到论文对应小节。
3. 若需追溯来源/复现命令、英文段落或数据版本，进入该子文件夹的 `other/`：
   - `other/about.md`：图源路径、生成脚本/命令、口径说明
   - `other/paper_fragment_en.md`：英文论文段落（可选）
   - `other/data.csv`：图片对应的数据版本（便于 AI/程序读取与核对）
   - `other/context_full.md`：重构前的原始上下文备份（保留“讲解括号注释”等）

当前对应论文主稿（草稿）：`MCM_Sim/26A/论文/相关文本信息/no8/_0131-1507-论文.md`

## data.csv 生成

Q1 各图的 `other/data.csv` 可通过脚本一键导出（会读取现有配置与报表并复现对应曲线）：

```bash
PYTHONPATH=MCM_Sim/26A/src python MCM_Sim/26A/src/scripts/export_q1_paper_material_data.py
```
