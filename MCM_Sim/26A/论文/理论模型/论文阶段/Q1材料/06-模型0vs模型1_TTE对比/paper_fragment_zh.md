# 可直接粘贴到论文的文本（中文）

为对齐赛题中“同样用法但续航差异显著”的现象，我们将智能手机的典型使用行为抽象为五类代表性场景（S1–S5），并以此驱动连续时间 SOC 模型计算耗尽时间 TTE。五类场景的口径如下（供读者理解 S1–S5 的含义）：

| 场景         | 典型行为                             |
|--------------|--------------------------------------|
| S1 待机/轻度 | 低亮或熄屏，低吞吐，后台少           |
| S2 浏览/社交 | 频繁切换加载，后台开启应用较多       |
| S3 视频/直播 | 负载较稳但使用时间长，缓存大         |
| S4 游戏      | CPU/GPU 使用度高，温度高             |
| S5 导航/通话 | 蜂窝多，GPS 常开，弱信号惩罚明显     |

为了剥离并量化“停止准则/电池端机理”对续航估计的影响，我们比较两种模型：
- **Model-0（SOC 阈值）**：在固定 \(SOC\le SOC_{\min}\) 时终止放电，等价于假设所有剩余电量都可被利用；
- **Model-1（截止电压）**：在端电压首次跌破截止电压 \(V_{\mathrm{cut}}\) 时终止，并显式考虑欧姆压降与极化压降，因此高负载下可能出现欠压提前关机。

图 Q1-06：五类典型场景下的耗尽时间 TTE 雷达图对比。五个顶点分别对应 S1–S5；半径为 TTE（小时，**对数刻度**，刻度示例 2/4/8/16/32h）。蓝色多边形为 Model-0（SOC 阈值），橘色多边形为 Model-1（截止电压）。透明填充用于叠加显示两种停止准则下的差异。

从图中可见，在“游戏/导航”等高负载场景下，Model-1 相比 Model-0 给出更短的 TTE，反映出端电压压降会使系统在电量尚未真正耗尽时提前触发关机；这一定性结果与真实手机“突然掉电/电量虚标”的体验相一致。
