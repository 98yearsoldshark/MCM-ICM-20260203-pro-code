# Q3 材料（Sensitivity and Assumptions）

本目录用于写作赛题 **Q3：Sensitivity and Assumptions**（“当你改变建模假设、参数取值，以及使用模式波动时，预测结果如何变化”）。

目录组织约定：
- 每个子文件夹对应 **1 张建议插入论文的图**（`figure.png`，来自 `MCM_Sim/26A/src/out_plots/q3/paper/` 或 Q3 的观测数据实验出图目录）。
- 每个子文件夹根目录仅保留（便于写作时“只看中文+图”）：
  - `figure.png`：论文版图片（干净、可直接插入）
  - `paper_fragment_zh.md`：中文论文上下文片段（含插图位置 + 图题 + 解读段落）
- 其余材料统一收纳到 `other/`（便于追溯与复现）：
  - `other/about.md`：中文说明（图源路径、生成脚本、关联报表、建议插入位置）
  - `other/paper_fragment_en.md`：英文论文上下文片段（可选）
  - `other/data.csv`：图片对应的数据版本（便于 AI/程序读取与核对）
  - `other/data_raw.csv`：可选，原始/更细粒度数据（仅部分图会提供）

建议正文优先级（从高到低，可按版面取舍）：
1. `01-全局敏感性-PRCC_TTE均值`：参数不确定性对续航均值的影响（全局敏感性）
2. `02-全局敏感性-PRCC_欠压风险裕量`：参数不确定性对“欠压/崩塌风险”的影响（更贴“突然掉电”）
3. `05-假设检验-功耗机制消融`：假设/机制消融，回答“drivers of rapid drain”与“surprisingly little”
4. `09-不确定性分解-参数vs使用波动`：把总波动拆成“参数/慢变量”vs“使用波动”
5. `11-观测数据分解-使用×老化×交互`：用公开数据锚定 usage/aging 的方差分解（更贴题面“真实使用+历史/老化”）
6. `14-使用波动-突发性sweep_均值固定`：模型内构造“均值固定、只改突发性”的波动强度对照（最贴 Q3 fluctuations，且不依赖许可不明数据）
7. `13-观测锚定-NASA脉冲负载电压下陷`：用公开电池实验展示“脉冲负载→电压下陷→逼近 cut-off→休止回弹”，支撑欠压风险机理
8. `10-观测轨迹检验-α波动强度sweep`：用实测功耗轨迹做可控波动实验（更强因果对照；**是否可进最终提交取决于上游数据许可是否明确**）

其余图（03/04/06/07/08）更适合：
- 作为 Q3 的补充论证（正文小图），或
- 放入 Appendix（不占主叙事篇幅但增强说服力）。

建议附录（Appendix）优先放：
- `12-先验来源表-参数区间与来源`：把敏感性/方差分解用到的先验区间与数据锚定来源一次性讲清楚，减少“先验主观”质疑。
