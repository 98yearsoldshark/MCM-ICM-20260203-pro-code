# 2 电池本体：二阶 Thevenin ECM + 热模型（连续时间 ODE）

采用二阶等效电路（OCV + R0 + 两支 RC 极化）并加入热模型，形成连续时间机理方程组。

## 2.1 状态方程与输出

x(t)=[SOC(t),U1(t),U2(t),T(t)]^T

dSOC/dt = - η_c(T,SOH) * I(t) / Q_eff(SOH,T),   Q_eff = Q_nom * SOH * κ_Q(T)

dU1/dt = -U1/(R1 C1) + I/C1

dU2/dt = -U2/(R2 C2) + I/C2

C_th dT/dt = I(t)^2 R0(SOC,T,SOH) + α_chip P_chip(t) - hA (T - T_amb(t))

V_term(t)=OCV(SOC,T) - I·R0(SOC,T,SOH) - U1 - U2

## 2.2 放电截止电压设定

考虑不同截止电压会影响可用容量与寿命，本文采用保守策略设定：

V_cut = 3.3 V  （主设定）

并在敏感性中将 V_cut 扰动（例如 3.2–3.4V），呈现“截止电压—续航—寿命/安全裕度”的权衡。

# 3 手机负载功耗：连续主模型 + 离散事件辅助归因（不改变核心）

## 3.1 总功耗合成与 PMIC 效率（η_PMIC 设为常量）

由于热耦合效应与手机活动强度交织，且缺乏可直接采集的 PMIC 效率曲线数据，本文将 η_PMIC 视为常量以避免不可辨识。

P_device(t)=P_base + P_screen(t) + P_cpu(t) + P_gpu(t) + P_net(t) + P_gps(t) + P_bg(t) + P_int(t)

P_batt(t)=P_device(t) / η_PMIC

η_PMIC = η0 ∈ (0,1]  （常量；建议先验 0.90–0.95，并在敏感性中扰动）

## 3.2 屏幕功耗：通用模型 A1

P_screen(t)=P_scr,off + ScreenOn(t)·( k_b·B(t)^{γ_b} + k_r·r(t) + k_APL·APL(t) )

## 3.3 CPU 功耗：big.LITTLE（大核/小核）

P_cpu(t)= k_big·u_big(t)^{γ_big} + k_lit·u_little(t)^{γ_lit} + P_cpu,idle

约束：k_big≥k_lit≥0，γ_big,γ_lit≥1

P_gpu(t)=k_gpu·u_gpu(t)^{γ_g}

若只能采到总 CPU 利用率 u_cpu(t)，可用分配系数 ρ(t) 近似：u_big=ρu_cpu，u_little=(1-ρ)u_cpu；ρ 可设分段常数或做敏感性扫描。

## 3.4 网络功耗：方案A（尾态随应用强度变化）

考虑网络尾态可能随应用强度（高/中/低）变化。为保持连续时间与可解释性，采用连续强度门控：尾态时间常数随应用强度 u_app(t) 平滑变化。

应用强度（连续）：

​    u_app(t)=clip( ω_c·(u_big(t)+u_little(t)) + ω_g·u_gpu(t), 0, 1 ),  ω_c,ω_g≥0, ω_c+ω_g=1

尾态时间常数（随强度变化，分网络类型 m）：

​    τ_m(u_app)=τ_{m,low} + (τ_{m,high}-τ_{m,low})·σ((u_app-u0)/Δu)

​    σ(z)=1/(1+e^{-z})

尾态动力学：

​    dx_net/dt = - x_net/τ_m(u_app(t)) + a_q,m · q(t) + a_s,m · ψ_m(S_m(t))

功耗映射：

​    P_net(t)=P_idle,m + b_q,m · q(t) + b_x,m · x_net(t)

弱信号惩罚：ψ_m(S)= (S_ref,m - S)_+ ,   q(t) 单位 KB/s；P_net 不区分上下行

## 3.5 GPS、后台与交互项（保留乘积交互；热影响由电池热模型体现）

P_gps(t)=k_gps·g(t)

P_bg(t)=k_bg·w(t)

P_int(t)=k_nc·q(t)·(u_big(t)+u_little(t)) + k_cg·(u_big(t)+u_little(t))·u_gpu(t)

说明：虽然 η_PMIC 取常量，热效应仍通过电池热方程与 R0(SOC,T,SOH) 的温度依赖进入，影响欠压与 Δ<0 风险。

## 3.6 离散分段分析（用于更好解释 P_total）

按网络类型段、亮屏段、APP 事件段计算能量贡献；该分析不改变连续动力学。

E_{net,k}=∫_{t_k}^{t_{k+1}} P_net(t) dt，E_{screen,k}=∫ P_screen(t) dt，…

E_net^{Wi‑Fi}=Σ_{k:m=Wi‑Fi} E_{net,k}，同理 LTE/5G

# 4 电池侧电流求解：功率守恒闭环（隐式代数约束）

V_oc = OCV(SOC,T) - U1 - U2，V_term=V_oc - I·R0

P_batt = V_term·I = V_oc I - R0 I^2

R0 I^2 - V_oc I + P_batt = 0

I(t) = [ V_oc - sqrt( V_oc^2 - 4 R0 P_batt ) ] / (2 R0)

Δ(t)=V_oc^2 - 4 R0 P_batt

# 5 TTE：首次到达时间（非回归）

终止事件： (i) V_term(t) ≤ V_cut   (ii) SOC(t) ≤ SOC_min   (iii) Δ(t) < 0

TTE = inf{ t≥0 : 事件触发 }

## 6.2 约束检查（验收清单）

• 正性：R0,R1,R2,C1,C2,C_th,hA,τ_{m,low},τ_{m,high} >0；功耗系数 ≥0；0<η0≤1。

• 单调性：放电 dSOC/dt≤0；OCV(SOC) 单调不减。

• 量纲：q 用 KB/s 时 b_q,m 单位匹配；热方程量纲为 J/s。

• 可行性：Δ(t)=V_oc^2-4R0P_batt ≥0；频繁 Δ<0 需回退负载或参数。

• 边界：SOC∈[0,1]；温度在合理范围；越界触发保护并记录。

• 能量一致：∫P_batt dt 与理论可用能量量级一致。

# 7 敏感性分析（包含网络门控与 η0）

每场景做：局部敏感性 + 全局敏感性（采样+PRCC）+ 结构消融（检验门控必要性）。

## 7.1 局部敏感性（Local）

S_j = (θ_j/TTE) · ( TTE(θ_j(1+ε)) - TTE(θ_j(1-ε)) ) / (2εθ_j),  ε=0.05

# 9 电池老化（SOH）建模：容量衰减 + 内阻上升（机理化接入）

在单次放电预测的小时级时间尺度内，电池健康状态 SOH 可视为常量（慢变量）。本文将老化通过两条机理路径接入主模型：有效容量 Q_eff 的衰减与欧姆内阻 R0 的增大。这不会改变连续时间方程结构，仅改变参数随 SOH 的依赖。

## 9.1 容量衰减：Q_eff(SOH)

Q_eff(SOH,T) = Q_nom · SOH · κ_Q(T)

dSOC/dt = - η_c(T,SOH) · I(t) / Q_eff(SOH,T)

解释：SOH↓ 表示可用容量减少，同样电流下 SOC 下降更快，从而缩短 TTE。

## 9.2 内阻上升：R0(SOC,T,SOH)

采用乘性增益表示老化导致的内阻上升：

R0(SOC,T,SOH) = R0_base(SOC,T) · ( 1 + α_R · (1 - SOH) )

其中 α_R ≥ 0 为老化增阻系数（常量）

解释：SOH↓ 使 R0↑，在恒功率负载闭环下更容易触发欠压或判别式 Δ<0（电压崩塌风险上升），因此老化不仅减少续航，还会提高“提前关机/不可预测耗尽”的概率。

## 9.3 可选扩展（附录）：慢时间尺度 SOH 演化方程

若题目需要讨论长期寿命，可在附录给出一个温度—电流应力驱动的连续时间退化模型：

dSOH/dt = - k_deg · |I(t)|^p · exp( -E_a / (R_gas · T(t)) )

（小时级放电中该项变化很小，主文可将 SOH 视为常量并通过敏感性扫描体现老化影响。）

# 10 老化敏感性与输出建议（加入题目第 3 问）

将 SOH 与 α_R 纳入敏感性分析：对每个场景进行 SOH 扫描与 PRCC 排名，给出老化对续航与提前关机风险的影响。

## 10.1 SOH 扫描（建议展示）

选择 SOH∈{1.0,0.9,0.8}（或连续扫描 0.7–1.0），对每场景输出：TTE(SOH)、Pr(V_term≤V_cut)、Pr(Δ<0)、关机剩余 SOC 分布。

## 10.2 将 SOH/α_R 纳入 PRCC 参数集合

在全局敏感性采样中加入 SOH 与 α_R：

SOH ~ Uniform(0.7, 1.0)   （或按设备状态设更窄范围）

α_R ~ Log-Uniform(0.1, 3.0)   （示例范围，可按文献/经验调整）

若某场景中 SOH 或 α_R 的 |PRCC| 较大，说明该场景对老化更敏感（例如高功率游戏/弱信号蜂窝导航）。
