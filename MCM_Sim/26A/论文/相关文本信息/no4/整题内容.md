# MCM A题 智能手机电量消耗建模
Smartphones are indispensable tools in modern life, yet their battery behavior often seems unpredictable. On some days a phone may last the whole day; on other days it drains rapidly before lunch. Although some users attribute this to "heavy use," the true drivers of battery depletion are more complex. Power consumption depends on the interplay of screen size and brightness, processor load, network activity, and background applications that continue drawing energy even when the device appears idle. Environmental conditions such as temperature further complicate matters: some batteries lose effective capacity in cold weather and may overheat under sustained heavy use. A battery's behavior is also influenced by its history and how it has been charged during its lifetime.

智能手机是现代生活中不可或缺的工具，但其电池表现常常显得难以捉摸。有时手机能持续工作一整天，有时却在午前就电量告急。尽管部分用户将其归咎于“重度使用”，但电量消耗的真正驱动因素要复杂得多。

不能考虑简单的线性/非线性叠加，应该去考虑他们的相互影响关系
$$P \approx P_{\text{screen}} + P_{\text{CPU}} + P_{\text{network}} + P_{\text{background}}$$

以上是错误的简单叠加，而应该是如下的综合函数 $P((Sto))$
$$P(t) = f\left(S_{\text{screen}}(t), S_{\text{SoC}}(t), S_{\text{network}}(t), S_{\text{OS}}(t), S_{\text{thermal}}(t)\right)$$

因此要更多地去查阅资料，确定他们的相互影响关系

1.  **状态转移**
    每个子系统（屏幕 / CPU / 网络）都有自己的状态机，但状态转移是相互触发的。

    例如：
    Screen OFF
    ↓ unlock
    Screen ON → CPU min freq ↑ → DRAM active → Network allowed

    功耗由：当前状态 + 未来一段时间内可达状态集合 决定

2.  **反馈环**
    至少存在三类关键反馈：
    - **热反馈**
      高负载 → 温度 ↑ → 限频 → 执行时间 ↑ → 总能耗 ↑
    - **交互反馈**
      卡顿 → 用户继续操作 → 屏幕常亮 → 功耗 ↑
    - **网络尾能量反馈**
      零散请求 → RRC 不降态 → 平均功耗 ↑

捋清楚耗电过程的原理

构建层级关系：物理层 → 电池等效层 → 系统功耗层 → 时间序列/预测层

### 荷电状态（State of Charge）
$SOC(t) \in [0,1]$
- 含义：时刻 $t$ 电池剩余可用电荷量占比
- $SOC=1$：满电
- $SOC=0$：系统认为“电量耗尽”（非化学意义上的 0）

### 2. SOC 动力学方程
$$
\frac{d\ SOC(t)}{dt} = -\frac{I(t)}{Q_{eff}(t)}
$$

| 变量 | 含义 | 单位 |
| ---- | ---- | ---- |
| $I(t)$ | 电池放电电流（正值表示放电） | A |
| $Q_{eff}(t)$ | 有效可用容量（随状态变化） | Ah |

### 3. 标称与有效容量
$$
Q_{eff}(t) = Q_0 \cdot f_T(T(t)) \cdot f_C(I(t)) \cdot f_A(A)
$$

| 符号 | 含义 |
| ---- | ---- |
| $Q_0$ | 新电池在标准条件下的标称容量 |
| $f_T(\cdot)$ | 温度对容量的修正函数 |
| $T(t)$ | 电池或电芯温度 |
| $f_C(\cdot)$ | 放电倍率（电流）影响函数 |
| $f_A(\cdot)$ | 老化（SOH）影响函数 |
| $A$ | 老化指标（循环数 / SOH） |

## 二、电池电压与等效电路层
### 4. 电池端电压
$$
V_{bat}(t) = V_{OC}(SOC(t)) - I(t)\ R_{int}(SOC(t),T(t))
$$

| 变量 | 含义 | 单位 |
| ---- | ---- | ---- |
| $V_{bat}(t)$ | 电池端电压 | V |
| $V_{OC}(SOC)$ | 开路电压（OCV-SOC 曲线） | V |
| $R_{int}(\cdot)$ | 等效内阻 | Ω |

说明：这是一阶等效电路模型（Rint），已足够用于续航预测。

## 三、系统功耗 → 电池电流映射层
### 5. 系统功耗到电流的关系
$$
I(t) = \frac{P_{sys}(t)}{\eta(t)\ V_{bat}(t)}
$$

| 变量 | 含义 |
| ---- | ---- |
| $P_{sys}(t)$ | 手机系统瞬时功耗 |
| $\eta(t)$ | 电源管理/变换效率 |
| $V_{bat}(t)$ | 当前电池端电压 |

### 6. 转换效率
$\eta(t) \in (0,1]$
- 表示 DC-DC、LDO 等电源路径的综合效率
- 可能随负载、温度变化
- 工程模型中常取常数或分段常数

## 四、系统功耗的状态驱动模型
### 7. 功耗的状态函数形式
$$
P_{sys}(t) = P(s_{screen}(t), s_{SoC}(t), s_{network}(t), s_{OS}(t))
$$

| 状态 | 含义 |
| ---- | ---- |
| $s_{screen}(t)$ | 屏幕状态 |
| $s_{SoC}(t)$ | SoC 工作状态 |
| $s_{network}(t)$ | 网络连接状态 |
| $s_{OS}(t)$ | 操作系统调度状态 |

### 8. 可展开的功耗分解
$$
P_{sys}(t) = P_0 + P_{screen}(b(t),r(t)) + P_{CPU}(u(t)) + P_{net}(m(t))
$$

| 符号 | 含义 |
| ---- | ---- |
| $P_0$ | 基础静态功耗 |
| $P_{screen}$ | 屏幕功耗函数 |
| $b(t)$ | 屏幕亮度 |
| $r(t)$ | 刷新率 |
| $P_{CPU}$ | 处理器功耗 |
| $u(t)$ | CPU/GPU 利用率 |
| $P_{net}$ | 网络功耗 |
| $m(t)$ | 网络状态（RRC 状态） |

## 五、连续时间总模型（核心）
### 9. SOC 演化总方程
$$
\frac{d\ SOC(t)}{dt} = -\frac{P_{sys}(t)}{\eta(t)\ V_{bat}(t)\ Q_{eff}(t)}
$$
- 状态变量：$SOC(t)$
- 输入：用户/系统行为驱动的功耗
- 参数：电池与硬件特性

## 六、时间积分形式（用于计算）
### 10. SOC 的积分解
$$
SOC(t) = SOC(0) - \int_{0}^{t} \frac{P_{sys}(\tau)}{\eta(\tau)\ V_{bat}(\tau)\ Q_{eff}(\tau)} d\tau
$$

## 七、剩余可用时间（RUL）定义
### 11. 剩余时间求解
$$
T_{remain} = \int_{t_0}^{t_{empty}} dt = \int_{SOC(t_0)}^{0} \frac{\eta(t)\ V_{bat}(t)\ Q_{eff}(t)}{-P_{sys}(t)} dSOC
$$

| 符号 | 含义 |
| ---- | ---- |
| $t_0$ | 当前时刻 |
| $T_{remain}$ | 剩余可用时间 |
| $P_{sys}(t)$ | 预测的未来功耗 |
