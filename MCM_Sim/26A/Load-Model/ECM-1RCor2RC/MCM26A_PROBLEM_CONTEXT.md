# ECM-1RCor2RC 与 2026 MCM 赛题 A 的关系（写论文/做仿真用）

赛题位置（本仓库整理版）：
- `MCM_Sim/26A/论文/赛题/A中文纯文本.md:1`
- `MCM_Sim/26A/论文/赛题/A英文纯文本.md:1`

赛题 A 强调：必须建立**连续时间（continuous-time）**电池模型，输出 `SOC(t)`，并据此预测 **TTE（Time-to-Empty）**，再做敏感性分析与建议；不能只做离散拟合/黑盒回归。

本目录 `ECM-1RCor2RC/` 的定位：提供一个“可写进论文的连续时间 ODE + 可运行的最小仿真”，让你能把 **功耗/电流输入** 转成 **SOC、电压、截止事件**，从而得到 `SOC(t)` 与 `TTE`。

---

## 1) 为什么选 ECM（1RC/2RC）

对手机电池而言，最基础的能量/库伦计模型只能给出 SOC 的积分关系，但很难解释：
- 脉冲负载下电压瞬时下跌/恢复（极化效应）
- “同样 SOC，不同负载历史导致电压不同”的动态滞后
- 截止电压触发导致的 TTE 变化（尤其在低温/老化/大电流时更明显）

1RC/2RC 的 Thevenin ECM 用很少的状态量（SOC + 1~2 个极化状态）就能把这些现象表达出来，并且仍然是连续时间 ODE（符合题意）。

---

## 2) 你可以直接写进论文的控制方程（示例）

以 2RC 为例：
- 状态：`x = [SOC, V1, V2]^T`
- 连续时间：
  - `dSOC/dt = - I / (3600*Q)`
  - `dVj/dt = -Vj/(Rj*Cj) + I/Cj`，j=1,2
  - 端电压：`V = OCV(SOC) - I*R0 - V1 - V2`

TTE 终止条件（建议至少包含）：
- 电压截止：`V <= V_cut`
（可选）SOC 下限：`SOC <= SOC_min`

---

## 3) 本目录提供的内容如何服务赛题四个要求

1. Continuous-Time Model：给出 ODE（上节）与离散化（用于数值求解）
2. Time-to-Empty：用截止电压事件计算/近似 TTE，并可解释“为何某些负载更耗命”
3. Sensitivity：对 `Q, R0, R1C1, R2C2, OCV` 等做敏感性分析（温度/老化可等效为参数变化）
4. Recommendations：把“最影响 TTE 的驱动因素”翻译成用户/系统策略（降亮度、限频、换网络、抑制后台等）

## 5) 快速验证（保证你写的方程没跑偏）

- 0 电流时：`V1/V2` 指数衰减到 0，端电压回到 `OCV(SOC)`
- 脉冲电流：端电压先瞬降，随后缓慢恢复；2RC 会比 1RC 多一个更慢的“尾巴”
- SOC 单调：放电（I>0）SOC 下降；符号搞反是最常见的 bug

运行 demo：
- `python3 MCM_Sim/26A/Load-Model/ECM-1RCor2RC/demo/demo_ecm_pulse.py`
