# Q1 可直接引用的方程（ECM 1RC/2RC）

本文件给出“写进论文 Q1 的最小方程组”，用于证明你们的模型是 **continuous-time**（显式 ODE/ODE system），并且机理明确。

记号约定（与本项目保持一致）：

- 电流 `I(t)`：**放电为正**（`I>0` 时 SOC 下降）
- 容量 `Q`：Ah；库仑量 `Q_C = 3600·Q`
- 参数：`R0, R1, R2`（ohm），`C1, C2`（F）
- 状态：`SOC(t)∈[0,1]`；极化支路电压（过电势）`V1(t), V2(t)`

---

## 1RC Thevenin（一个时间常数）

**SOC 动力学（库仑计数）**

`dSOC/dt = - I(t) / (3600·Q)`

**极化支路（R1||C1）**

`dV1/dt = -V1/(R1·C1) + I/C1`

**端电压方程**

`V(t) = OCV(SOC(t)) - I(t)·R0 - V1(t)`

解释：
- `I·R0` 是“瞬时欧姆压降”（电流一变，电压立刻跳变）
- `V1` 体现“松弛/恢复”（电流停止后电压缓慢回升）

---

## 2RC Thevenin（两个时间常数：快 + 慢）

在 1RC 基础上增加一个更慢的极化支路 `R2||C2`：

`dV2/dt = -V2/(R2·C2) + I/C2`

端电压变为：

`V(t) = OCV(SOC(t)) - I(t)·R0 - V1(t) - V2(t)`

直观含义：
- `τ1=R1C1`：秒级（快松弛）
- `τ2=R2C2`：分钟级（慢松弛）

---

## 离散化（用于数值仿真/滤波器，零阶保持常用写法）

对每个极化支路 `j∈{1,2}`，令：

- `a_j = exp(-Δt/(Rj·Cj))`
- `b_j = Rj·(1-a_j)`

则：

- `SOC_{k} = SOC_{k-1} - (Δt/(3600·Q))·I_{k-1}`
- `Vj_{k} = a_j·Vj_{k-1} + b_j·I_{k-1}`
