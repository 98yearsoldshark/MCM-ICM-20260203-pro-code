## 1 模型范围（按阶段推进，确保每一步可验证）

### Phase A（先跑通、先验检验）

1) Model-0（`H + L/J/M/F`）在常值资源 `R=R0` 下：
- 数值稳定、非负性、存在合理稳态或振荡（与 `tau/gamma` 一致）
- 指标定义与输出表结构确定

实现口径说明（避免“宿主不反作用七鳃鳗”的不合理）：

- 宿主 `H` 对七鳃鳗寄生期到成体的成熟率有饱和影响：  
  `mu_J_eff = mu_J * H/(H+K_HJ)`（`K_HJ` 为半饱和常数；若取 0 则表示总是饱和）  
  这样 `J` 对 `H` 的伤害会反过来降低未来成体与繁殖，形成闭环反馈。

2) 在季节资源下做 sanity check：`R(t)=R0(1+A sin(2πt/T))`

### Phase B（Z 主线：随机环境 bet-hedging）

3) 在马尔可夫丰歉年下，固定策略 vs `S_var(θ)` 扫描，输出 bet-hedging 核心图。

### Phase C（第三方受益者）

4) Model-1/2（单受益者）先做常值资源下入侵阈值验证，再上随机环境。
5) Model-3（双受益者）作为统一扩展示范（不追求铺满所有参数）。

## 2 时间尺度与数值推进方式（保持 ODE，避免 DDE 复杂度）

### 2.1 时间单位

- 统一以 “年” 作为时间单位。
- 所有速率参数（`mu_J, d_*` 等）都按 “每年” 计。

### 2.2 环境切换与 ODE 求解（推荐的最整洁做法）

- 环境过程在年度步长 `Δ=1 year` 更新一次；
- 在每个年度区间 `[t, t+1]` 内，把 `R(t)` 视为常数 `R_t`；
- 对该区间用 ODE 求解器积分（例如 `solve_ivp`），得到区间末状态作为下一年初值。

优点：

- 逻辑清晰：环境序列与动力学积分解耦；
- 便于复现：同一条环境序列可重复用于所有策略（配对对照）。

### 2.3 “记忆长度 w” 的实现（用低通滤波代替显式延迟）

为了避免 DDE（延迟微分方程）带来的实现复杂度，将窗口平均近似为一阶滤波：

```
dx_bar/dt = (x(t) - x_bar)/w
```

解释：

- `x_bar` 近似近期 `x` 的平滑历史；`w`（年）越大越“保守”
- `w=0` 视为极限情况：`x_bar=x`（瞬时响应）

然后 `p_m` 用 `x_bar` 驱动：

```
p_m = 0.56 + 0.22*(1 - x_bar^gamma)
```

说明：这是对 `x_hist(t)=mean_{s∈[t-w,t]} x(s)` 的可控近似；论文里只需说明“用低通滤波近似历史窗口”即可。

## 3 随机环境（Z 主亮点）：两态马尔可夫丰歉年

### 3.1 环境序列生成

`E_t ∈ {L,H}`：

```
P(E_{t+1}=H | E_t=L) = p_LH
P(E_{t+1}=L | E_t=H) = p_HL
```

资源赋值：

```
R_t = R_L if E_t=L
R_t = R_H if E_t=H
```

### 3.2 默认设定（主文展示 + 少量敏感性）

主文固定：

- `Δ=1 year`
- `R_H/R_L = 5`
- 自相关：`p_LH=p_HL` 取 `{0.5, 0.2}`（可选 `{0.1}` 极端）

敏感性：

- `R_H/R_L ∈ {3,10}`

### 3.3 配对对照（common random numbers）

为了让不同策略的差异更“干净”：

- 先生成 `J` 条环境序列（长度 `T` 年），保存下来；
- 所有策略在同一批序列上跑，形成配对比较（显著降低蒙特卡洛噪声）。

推荐规模（够用且不贵）：

- `T=200` 年
- `J=200~500` 条序列

## 5 指标定义（避免后期“算出来但写不进论文”）

### 5.1 核心状态

- 七鳃鳗总量：`N = L+J+M+F`

### 5.2 主指标（Z 主线：适应度/风险）

主指标：准灭绝概率

```
P_ext = P( min_t N(t) < N_q )
```

阈值取相对阈值（降低主观性）：

- `N_q = q * N_ref`
- 基线 `q=0.05`；敏感性 `q∈{0.01,0.10}`
- `N_ref` 取 `R=R_bar`（马尔可夫平稳平均资源）下的常值稳态：

```
R_bar = pi_L*R_L + pi_H*R_H
N_ref = N*(R=R_bar)
```

为保证不同策略的 `P_ext` 可直接比较（同一把尺子），实现上推荐采用**共同参考稳态**：

- 选定一个参考策略（例如 `S_var(gamma=1,w=3)`）
- 在 `R=R_bar` 下跑到稳态得到 `N_ref`
- 用同一个 `N_q=q*N_ref` 评估所有策略（配合同一批环境序列做配对对照）

并在敏感性里补一种“相对崩盘”口径（可选）：对每个策略用其自身 `N_ref(strategy)` 定义 `N_q`，看结论是否改变。

辅指标（解释机制）：

- `Lambda_rec`：恢复阶段几何平均增长（从 `N_low` 到 `N_target` 的 log 增长率）
- 可选 `Lambda_inv`：随机入侵增长率（理论加分，但不是必须）

### 5.3 生态代价（避免单目标优化）

宿主安全指标（与 Q1 对齐）：

```
P_host = P( min_t H(t) < H_safe )
```

`H_safe` 也建议取相对阈值（例如常值资源稳态的 20% 或 30%），并做敏感性。

## 6 输出与目录整洁约定（写代码前先定）

建议将仿真输出统一放到一个根目录，例如：

- `MCM_Sim/24A/outputs/`（每次运行一个时间戳子目录）

每次运行生成：

- `config.json`：本次运行的所有参数（含随机种子、参考稳态、阈值）
- `env_sequences.npz`：环境序列（用于配对对照复现；包含 states 与 R）
- `runs.csv`：每个实验一行的汇总表（主表）
- `trajectories/`：必要时保存少量代表性轨迹（不要全存，太大）
- `figures/`：自动生成的论文图（PNG/SVG）

命名原则：

- 文件名包含：`model`、`env`、`strategy`、`gamma`、`w`、`seed`
- 所有数值保留统一小数位（便于 diff）

## 7 一致性/正确性检查（跑仿真前先写成 checklist）

每次开始大规模扫描前先验证：

- 正性：所有状态变量不出现明显负数（数值误差可容忍 `-1e-12` 并截断）
- 边界：`R→0` 时 `p_m→0.78`；`R` 高时 `p_m→0.56`
- 极端性别比：`M→0` 时繁殖项接近 0（`phi(M,F)→0`）
- 无寄生：`J→0` 时 `H` 近似逻辑斯蒂
- 配对对照：同一环境序列下，不同策略输出差异可解释且可复现（固定 seed）
