## 随机环境与 bet-hedging（Z 主亮点模块）

定位：把题目“可变性别比的利弊”从静态资源扩展到**随机丰歉年**，用“长期几何平均适应度/灭绝风险”给出更硬的结论。

核心观点一句话：

- 在随机环境中，策略优劣应以**几何平均（log-fitness）**衡量；可变性别比可通过“降低崩盘风险/提高恢复能力”实现 bet-hedging，即使其算术平均繁殖率不一定最高。

---

## 0 bet-hedging 是什么（为什么不是看“平均增长率”）

**定义（生态/进化语境）**  
bet-hedging（风险分散策略）指：在环境不可预测时，个体/种群牺牲一部分“好年份的收益”，换取更低的波动与更小的崩盘风险，从而提高长期成功率。

**关键原因：种群增长是“乘法过程”**  
若每个时间步的增长倍数是 `λ_t`（例如一年后 `N_{t+1}=λ_t N_t`），则长期增长由几何平均控制：

```
log(长期增长率) = lim (1/T) Σ log(λ_t)  ≈  E[log λ]
```

方差会惩罚几何平均（Jensen 不等式）：`E[log λ] < log(E[λ])`。  
因此“算术平均更大”的策略，可能长期更差、甚至更容易灭绝。

**一个直觉例子**（写在讨论里很加分）：  
策略 A：好年翻倍 `λ=2`，坏年只剩 `λ=0.2`；各占 50%。  
算术平均 `E[λ]=1.1`（看起来“>1”）；但几何平均 `exp(E[log λ])=exp(0.5 log2 + 0.5 log0.2)≈0.63<1`，长期反而衰退。  
这就是 bet-hedging 研究中“均值会骗人”的经典点。

## 1 环境过程：两态马尔可夫丰歉年（可控相关性）

令环境状态 `E_t ∈ {L,H}` 表示“低资源年/高资源年”。在离散年度尺度（或每 `Δ` 年一次切换）下：

```
P(E_{t+1}=H | E_t=L) = p_LH
P(E_{t+1}=L | E_t=H) = p_HL
```

对应资源水平（幼体食物供给）：

```
R(t) = R_L  if E_t=L
R(t) = R_H  if E_t=H
```

两个很有用的可解释量（写进论文能加分）：

- 平稳分布：`pi_H = p_LH/(p_LH+p_HL)`, `pi_L = 1-pi_H`（长期“丰/歉”的比例）
- 平均“连续丰年长度”：`1/p_HL`；平均“连续歉年长度”：`1/p_LH`（环境自相关强弱）

说明：

- 用马尔可夫链的好处是：既能表示随机，又能控制“连着好多年都很差/很好”的现实情形；这会显著影响延迟系统的稳定性与灭绝风险。

### 1.1 环境切换步长（Δ）怎么选

步长的选取原则：让“环境变化”与“性别决定/补充滞后”处在同一可解释尺度上。

推荐优先用 **年度步长 `Δ=1 year`**，理由：

- 题目机制发生在幼体生长历史上（年尺度更自然），且我们本来就引入 `tau`/窗口平均；
- 年度步长便于解释马尔可夫参数：`1/p_LH` 就是“连续歉年的平均长度（年）”；
- 竞赛写作更直观：坏年连发 3-5 年会怎样？策略如何降低崩盘风险？

你可以在敏感性里补两个极端情景，证明结论稳健：

- **弱相关**（近似 i.i.d.）：`p_LH≈p_HL≈0.5`（平均连段长度约 2 年）
- **强相关**（气候/人为长期偏差）：`p_LH≈p_HL≈0.1~0.2`（平均连段长度约 5-10 年）

注意：如果把 `Δ` 取很小（周/月），而 `p_m` 又依赖长窗口 `x_hist`，高频噪声会被平均掉，bet-hedging 信号反而变弱；所以不建议为“复杂”而取超细步长。

## 2 策略空间：把 `S_var` 做成“可调策略族”

固定策略（对照组）：

- `S_56`: `p_m ≡ 0.56`
- `S_78`: `p_m ≡ 0.78`
- `S_50`: `p_m ≡ 0.50`

可变策略（主角）建议不要只用一个 `S_var`，而是用一族 `S_var(θ)`，其中策略参数 `θ` 控制“响应强弱/记忆长度”：

- **敏感度** `gamma`：越大越阈值型、越容易过冲
- **记忆/窗口**：用 `x_hist`（窗口平均）替代瞬时 `x(t)`，窗口越长越“保守”

```
p_m(x) = 0.56 + 0.22*(1 - x^gamma)
p_m(t) = p_m( x_hist(t) )
```

bet-hedging 的直觉（写作模板）：

- 环境越“跳”、越不确定（方差大、相关性强），越需要保守策略（更长窗口/更小有效敏感度）以减少崩盘风险；
- 环境越稳定，越可以更敏感地追随资源变化以提高繁殖效率。

---

### 2.1 资源对比（R_H/R_L）怎么选

在我们的主模型中，真正驱动性别比的是归一化资源指标

```
u(t)=R(t)/(L+eps),  x=u/(u+K_u)
```

因此“资源对比”不是单纯 `R_H/R_L`，而是要让 `x` 在典型密度范围内能覆盖“偏低/偏高”两端（这样 `p_m` 才会明显摆动）。

竞赛里最稳妥的做法是：

- 先选一个中等对比作为基线：`R_H/R_L ≈ 3~10`
- 再在敏感性里扫 `3, 5, 10`（同时扫环境相关性 `p_LH,p_HL`），用热图/曲线展示 bet-hedging 结论对幅度与相关性的稳健区间

加分写法（把选择和锚点联系起来）：

- 我们选择 `R_L,R_H` 使得在典型幼体密度附近，`x` 能在低值与高值之间切换，从而将雄性比例推向赛题锚点的两端（低资源更偏雄、高资源更偏雌）。
- 同时因为 `x` 含 `L`（密度反馈），即使 `R` 外生，系统仍会出现“资源-密度-性别比-补充”的闭环，这比直接把 `p_m` 设成外生随机更贴近生态机制。

### 2.2 本项目的默认设定（已确定，用于主文展示）

为保证“可解释 + 可复现 + 不撑爆参数”，主文建议固定一套基线，再做少量敏感性：

- 环境切换步长：`Δ = 1 year`
- 资源对比（基线）：`R_H/R_L = 5`
- 资源对比（敏感性）：`R_H/R_L ∈ {3,10}`
- 环境相关性（用连段长度解释）：
  - 弱相关：`p_LH=p_HL=0.5`（平均连段约 2 年）
  - 强相关：`p_LH=p_HL=0.2`（平均连段约 5 年）
  - 极强相关（可选）：`p_LH=p_HL=0.1`（平均连段约 10 年）

策略扫描建议（参数少但信息增益大）：

- `θ = (gamma, window_length)`：扫描 `gamma` 与窗口长度（或用 `gamma` + 延迟 `tau` 替代窗口长度）
- 其余参数保持在合理范围内；用全局敏感性证明“结论稳健”，而不是“参数调出来的”

推荐的最小扫描网格（够用且不贵）：

- `gamma ∈ {0.5, 1, 2, 4, 8}`
- `window_length w ∈ {0, 1, 3, 5}`（单位：年；`w=0` 表示瞬时响应）

为避免再引入 `tau1,tau2` 两个参数，窗口平均可取最简形式：

```
x_hist(t) = mean_{s in [t-w, t]} x(s)
```

## 3 评价指标：用“几何平均 + 风险”而不是只看均值

记七鳃鳗总量 `N(t)=L+J+M+F`。

对 Q2（七鳃鳗利弊）的 bet-hedging 证据，推荐至少报告两类指标：

### 3.1 随机环境下的长期 log-fitness（几何平均增长率）

用于刻画“长期适应度”的核心量：

```
Lambda = lim_{T→∞} (1/T) * sum_{k=0}^{T-1} log( N_{k+1} / N_k )
```

注意：

- 有密度制约时稳态附近 `Lambda≈0` 是正常的；因此更推荐用“低密度/恢复阶段”的 `Lambda_rec`（见下一项）或做“入侵增长率”（线性化）作为补充解释。

### 3.2 风险导向指标（更像生态/管理语境）

- 准灭绝概率：`P(min_t N(t) < N_q)`（`N_q` 为准灭绝阈值）
- 恢复时间：在同一随机环境路径下，从小初值 `N(0)=N_low` 恢复到 `N_target` 的时间分布（中位数/分位数）
- 崩盘强度：`min(H)` 或 `P(H < H_safe)`（把“策略对生态系统的代价”写得更硬）

这些指标可以把“Z 奖亮点”讲得非常清楚：我们不仅关心平均水平，更关心在坏年份连发时系统是否会崩溃、是否能恢复。

为避免在“温和参数”下出现 `P_ext/P_host` 近乎全 0（或全 1）导致图信息量不足，建议固定再输出两类稳健指标（论文更好讲）：

- **尾部风险**：`q10_min_N / q10_min_H`（跨 Monte Carlo 重复的“最坏低谷”10%分位数）
- **几何平均**：`geom_mean_N / geom_mean_H`（时间加权几何平均，更贴近 `E[log]` 语境）

---

### 3.2.1 主指标建议（适应度选什么）

为了兼顾“竞赛可读性”与“科研硬度”，建议采用两层口径：

- **主指标（最推荐）**：准灭绝概率 `P(min_t N(t) < N_q)` 或其等价的“存活概率”  
  - 优点：最直观、最符合 bet-hedging 的风险语境；评委一眼看懂；还能自然串到 Q1（宿主越界概率）。
  - 处理主观性的办法：把 `N_q` 取为“相对阈值”（例如常值资源稳态的 1% 或 5%），并展示对阈值的敏感性。
- **辅指标（解释为什么）**：`Lambda_rec`（恢复阶段几何平均）或 `Lambda_inv`（随机入侵增长率）  
  - 作用：告诉评委我们不是“只看概率”，而是理解其背后的对数增长机制（乘法过程）。

本项目默认取法（与主文一致）：

- `N_q = q * N_ref`，基线 `q=0.05`（敏感性：`q∈{0.01,0.10}`）
- `N_ref` 取“常值资源在平均水平下的稳定平衡”：

```
R_bar = pi_L*R_L + pi_H*R_H
N_ref = N*(R=R_bar)
```

实现建议（保证策略间可比、便于配对对照）：

- 用一个**共同参考策略**（例如 `S_var(gamma=1,w=3)`）在 `R=R_bar` 下求稳态得到 `N_ref`
- 用同一个 `N_q=q*N_ref` 评估所有策略（这样 `P_ext` 是同一把尺子）
- 再做敏感性：把 `N_ref` 改成“各策略自身稳态”，检查结论是否改变（若不变，论文可信度更高）

## 3.3 可选（更硬核但仍可控）：随机入侵增长率（stochastic invasion growth rate）

如果你想把 bet-hedging 写得更像理论生态学（但不引入大量额外参数），可以用“七鳃鳗在低密度时能否增长”作为适应度定义。

做法：

- 先把系统放在“七鳃鳗几乎为 0”的边界平衡附近：此时宿主 `H≈K_H`（或其边界稳态）。
- 在该附近线性化七鳃鳗子系统，得到带随机环境切换的线性系统：

```
dX/dt = A(E_t) X,  X = (L,J,M,F)^T
```

则长期增长率是随机矩阵乘积的最大 Lyapunov 指数（可通过沿随机环境路径迭代 `X` 并取 `log ||X||` 的斜率估计）。

这段在论文里可以写成一句话（不必展开推导）：

- “我们在七鳃鳗稀有条件下估计其随机入侵增长率 `Lambda_inv`，并用 `Lambda_inv>0` 作为在随机环境下可持续的判据；不同性别比策略会改变 `Lambda_inv`，从而体现 bet-hedging 的优势。”

## 4 论文呈现：一张“最值钱”的 bet-hedging 图

建议把 bet-hedging 结果压缩成 1 张多子图（A/B/C）：

- (A) `Lambda_rec` 或“恢复成功率” vs `gamma`（或窗口长度）
- (B) 准灭绝概率 vs `gamma`（或窗口长度）
- (C) 宿主安全指标 `P(H<H_safe)` vs `gamma`

再加一句结论模板：

- “在高波动/强相关的随机环境下，`S_var(θ)` 存在一组最优/近最优参数区间，使准灭绝概率显著降低，同时对宿主的长期压力不劣于固定策略；这体现了可变性别比作为 bet-hedging 的生态意义。”

### 4.1 生成 bet-hedging 图的最小实验协议（方法加分点）

不写代码也建议在论文里把“实验怎么做”说清楚（评委会更信结论）：

1) 固定基线参数，并用 `R_bar=pi_L R_L + pi_H R_H` 定义参考稳态 `N_ref`（用于相对阈值 `N_q=qN_ref`）。
2) 生成 `J` 条长度为 `T` 的环境序列（两态马尔可夫链），并对所有策略使用**同一批环境序列**（common random numbers；相当于做配对对照，显著降低蒙特卡洛噪声）。
3) 对每条环境序列，在同一初值下分别运行 `S_var(θ)` 与固定策略 `S_56/S_78/S_50`，记录：
   - `I_ext = 1[min_t N(t) < N_q]`
   - `I_host = 1[min_t H(t) < H_safe]`
   - `T_rec`（若做恢复实验：从 `N_low` 到 `N_target` 的时间）
4) 汇总得到：
   - `P_ext = mean(I_ext)`，`P_host = mean(I_host)`，以及 `T_rec` 的中位数/分位数
5) 展示方式：
   - 对 `θ=(gamma, window_length)` 画热图/曲线，并标出“低 `P_ext` 且低 `P_host`”的近最优区域（可作为 bet-hedging 的策略选择结果）。

建议的规模（写在方法里即可，不必做得很大）：

- `T=200`（年尺度），`J=200~500`（环境路径条数）；用配对对照后，`J` 不需要特别大就能看出趋势。
