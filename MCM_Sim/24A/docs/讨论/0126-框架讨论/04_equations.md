## 共同组件（所有模型共享）

### 1) 资源 → 生长 → 性别比（题眼）

幼体人均资源：

```
u(t) = R(t) / (L(t) + eps)
x(t) = u(t) / (u(t) + K_u)   ∈ (0,1)
```

雄性比例反应范式（锚定题面 78%/56%）：

```
p_m(x) = 0.56 + 0.22 * (1 - x^gamma),   gamma>0
```

更贴近实证的写法（推荐用于高分论文叙事）：

- 性别分化发生在幼体期的一个窗口（而非瞬时决定），因此可用“延迟/窗口平均”的资源指标驱动 `p_m`：

```
x_hist(t) = mean_{s in [t-tau2, t-tau1]} x(s)   # tau2 > tau1 >= 0
p_m = p_m( x_hist(t) )
```

- 若不想引入窗口积分，可用最小替代：`p_m = p_m(x(t-tau))`。`tau` 的量级可取 3-5 年，并在敏感性分析中扫描（依据见 `09_paper_notes_0126_1333.md`）。

幼体转化（发育）速率（Monod 型；资源越足，越接近上限）：

```
mu_L(x) = mu_L_max * x
```

说明：

- `gamma` 控制敏感度：`gamma` 越大越像“阈值型性别决定”，更可能引入临界行为（振荡/多稳态）。
- 你也可以把 `p_m` 写成逻辑斯蒂形式，但务必保持两端锚点（0.78/0.56）。
- 若要体现“达阈值（体长/体重/脂质）才变态”的机制，可把 `mu_L` 替换为阈值/饱和型（Hill 函数）：

```
mu_L(x) = mu_L_max * x^k / (x^k + x0^k)
```

其中 `x0` 表示达到变态所需的“条件阈值”（资源/体况综合），`k` 控制阈值陡峭程度。

### 2) 受精/配对限制函数（把性别比连到繁殖成功）

推荐一个单调饱和、数值稳定的函数：

```
phi(M,F) = M / (M + hF)
```

解释：

- 若雄性很少，`phi≈0`，繁殖受限（符合“雄性不足导致未受精卵”的直觉）
- 若雄性充足，`phi→1`，繁殖主要由雌性决定（符合“雌性决定产卵量”）

### 3) 宿主鱼增长（生态系统基底）

最小版本：

```
dH/dt = r_H * H * (1 - H/K_H) - a * J * H
```

可选增强（寄生/接触饱和）：

```
dH/dt = r_H*H*(1 - H/K_H) - a * (J/(1+alpha*J)) * H
```

## Model-0（Baseline）：H + L/J/M/F

```
dL/dt = b * F * phi(M,F) - mu_L(x)*L - d_L*L
dJ/dt = mu_L(x)*L         - mu_J_eff(H)*J    - d_J*J
dM/dt = p_m(x)*mu_J_eff(H)*J     - d_M*M
dF/dt = (1-p_m(x))*mu_J_eff(H)*J - d_F*F
```

为了让“宿主鱼 H ↔ 七鳃鳗 J”形成双向反馈（更贴近生态系统而非单向压制），推荐让寄生期到成体的成熟率随宿主丰度饱和：

```
mu_J_eff(H) = mu_J * H/(H + K_HJ)
```

解释：

- 宿主充足：`mu_J_eff≈mu_J`（成熟/转化接近上限）
- 宿主稀缺：`mu_J_eff` 下降（寄生期更难维持/转化为繁殖成体），从而反过来降低未来繁殖

参数拆解建议（便于写“生物学依据/无数据校准”）：

- 若不显式写卵阶段，可将 `b` 视为“单位雌性的有效补充系数”：

```
b = fecundity * egg_to_larva_survival
```

其中 `egg_to_larva_survival` 可用约 0.063 的量级作为参考（见 `09_paper_notes_0126_1333.md`）。

重要说明（写进论文可加分）：

- 严格来说，性别由“幼体期资源”决定，因此 `p_m` 对应的是较早时刻的 `x`。  
  若想更真实，可引入一个发育延迟 `tau`：

```
p_m = p_m( x(t-tau) )
```

延迟往往是系统振荡的重要来源；你可以用它讨论 Q3（稳定性）中的“临界转变”。

## Model-1：Model-0 + B_L（七鳃鳗寄生虫/病原体）

设 `B_L` 的增长依赖七鳃鳗寄生期 `J`（传播链随宿主丰度增强）：

```
f_J(J) = J / (J + K_J)

dB_L/dt = eta_L*beta_L*f_J(J)*B_L - d_BL*B_L
```

并让 `B_L` 反过来增加七鳃鳗死亡（或降低转化成功）：

```
dJ/dt = ... - delta_L * g(B_L) * J
g(B_L) = B_L/(B_L + K_BL)   或  g(B_L)=B_L
```

为何好用：

- 在 `B_L≈0` 处可以做标准入侵分析，得到清晰的阈值条件（见 `05_analysis_plan.md`）。

## Model-2：Model-0 + B_H（宿主鱼机会性寄生虫/病原体）

关键思想：七鳃鳗寄生造成“伤口/应激”，提高宿主易感性，触发 `B_H` 增长。

定义一个“受损/易感性”指标（0-1）：

```
W(H,J) = (J*H) / (J*H + K_W)
```

则：

```
dB_H/dt = eta_H*beta_H*W(H,J)*B_H - d_BH*B_H
```

并让 `B_H` 增加宿主死亡：

```
dH/dt = ... - delta_H * q(B_H) * H
q(B_H) = B_H/(B_H + K_BH)   或  q(B_H)=B_H
```

这个模型对 Q4 特别有力：它展示“七鳃鳗 → 宿主受损 → 机会性寄生者获益”的间接机制。

## Model-3：双受益者并存（B_L + B_H）

把 Model-1 与 Model-2 叠加即可；重点是讨论二者的间接相互作用：

- `B_L` 抑制 `J` → 宿主受损减少 → `B_H` 入侵更难
- `B_H` 压低 `H` → `J` 更难维持 → `B_L` 失去宿主

论文里可用“参数平面入侵区”或“稳态/振荡区域图”展示这种耦合效应。

## 资源情景 R(t)（建议至少做 3 类）

1. **常值资源**：`R(t)=R0`（用于稳态与局部稳定分析）
2. **季节资源**：`R(t)=R0*(1 + A*sin(2πt/T))`（用于展示周期驱动下的响应与滞后）
3. **随机丰歉年**（冲高分）：两状态马尔可夫链 `R∈{R_L, R_H}`  
   目标：比较不同性别比策略在长期几何平均适应度/准灭绝风险上的差异（bet-hedging；见 `11_bet_hedging_module.md`）。

### 随机环境的最小写法（两态马尔可夫切换）

令离散环境状态 `E_t∈{L,H}` 表示低/高资源年（或每 `Δ` 年更新一次），转移为：

```
P(E_{t+1}=H | E_t=L) = p_LH
P(E_{t+1}=L | E_t=H) = p_HL
```

并把资源写成分段常数：

```
R(t) = R_L  if E_t=L
R(t) = R_H  if E_t=H
```

两个“可解释、可画图”的环境参数：

- 平稳分布（长期丰/歉比例）：`pi_H = p_LH/(p_LH+p_HL)`，`pi_L = 1-pi_H`
- 连续歉年平均长度：`1/p_LH`；连续丰年平均长度：`1/p_HL`

说明（和延迟强相关，适合写进 Q3/Q2）：

- 当环境自相关强（连续多年同一状态）且系统存在延迟 `tau` 时，更容易出现过冲与大幅波动；
- bet-hedging 比较的关键不是“均值最大”，而是“在坏年连发时不崩盘、能恢复”。

## 可选扩展 A：人类捕捞/控制（“门控”外部干预）

若你希望把“某些地区吃七鳃鳗/某些地区不吃”纳入讨论，可把人类视为一个外部控制项（无需再加一个“人类种群”变量）。

最简做法：对成体（或寄生期）加入额外死亡/移除率 `u(t)`：

```
dM/dt = ... - u_A(t)*M
dF/dt = ... - u_A(t)*F
```

门控（yes/no）的两种写法：

```
u_A(t) = u0 * I_region
u_A(t) = u_max / (1 + exp(-k*(A(t)-A_th)))   # 平滑阈值；A(t)=M+F
```

提醒（写进讨论会加分）：只捕捞成体虽然降低当年繁殖，但也可能通过降低未来 `L` 密度提高人均资源 `u(t)`，从而让 `p_m` 更偏雌、提高补充效率，出现“反弹更快”的间接效应；是否发生取决于参数与延迟。

## 可选扩展 B：个体食物异质性（“均值≠比例”的 Jensen 效应）

题面锚点（78%/56%）常以“平均资源水平”叙述，但性别决定可能发生在个体层面；若 `p_m(x)` 非线性，则：

```
E[p_m(x_i)] ≠ p_m(E[x_i])
```

两种可论文表述且易实现的方式：

1) **分布平均**：设个体资源 `x_i` 服从某分布（如 Beta/Lognormal），定义有效雄性比例为

```
p_m_eff(t) = E[p_m(x_i(t))]
```

2) **阈值决定**（对应“>0.5 全雌”的直觉）：若“雌性=资源超过阈值 x0”，则

```
P(female) = P(x_i > x0),  p_m = 1 - P(female)
```

若只想给出解析近似，可写二阶展开（用于解释“方差越大，性别比偏移越明显”）：

```
E[p_m(x_i)] ≈ p_m( x̄ ) + 0.5 * p_m''( x̄ ) * Var(x_i)
```

这类扩展非常适合用来冲“Z 奖”：它把“生态异质性/个体差异”引入，但不必改变主模型骨架。
