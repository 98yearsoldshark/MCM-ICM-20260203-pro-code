## 目标：把“四问”变成“可算的指标 + 可解释的机制”

论文里建议把四问对应到一组固定输出（指标），并用同一套对照实验贯穿：

- **对照主线**：`S_var` vs `S_56/S_78/S_50`（性别比策略）
- **模型对照**：Model-0（无受益者）→ Model-1/2（单受益者）→ Model-3（双受益者）

这样你可以把“因果链条”讲得很硬：策略变化 → 状态变化 → 指标变化 → 机制解释。

## Q1 生态系统影响：宿主鱼 H 的水平与波动

建议至少报告 4 个指标（常值资源/周期资源/随机资源都可算）：

1. `mean(H)`：长期平均宿主水平（生态健康代理）
2. `H_min`：长期最低宿主水平（崩溃风险代理）
3. `CV(H)`：变异系数（波动强度）
4. “安全阈值时间占比”：`P(H(t) < H_safe)`（如果你设置一个生态警戒线）

关键解释点（写作模板）：

- 性别比影响 `F`，而 `F` 通过繁殖项 `b*F*phi(M,F)` 影响未来 `L,J`，进而改变寄生压力 `a*J*H`；
- 所以“可变性别比”不是只改变七鳃鳗内部结构，而是通过时间滞后形成对宿主的系统性冲击/缓冲。

## Q2 七鳃鳗利弊：增长、持久性、风险与“内部代价”

建议输出分成三层：

### 2.1 持久性/增长（Persistence）

- 常值资源：比较各策略下是否存在共存稳态，以及稳态 `J*`、`F*`、总量 `N*`
- 随机资源（Z 主亮点）：比较 bet-hedging 表现（见 `11_bet_hedging_module.md`）
  - **几何平均/对数适应度**（建议用“恢复阶段”定义，避免稳态附近恒为 0）：  
    `Lambda_rec ≈ (1/T_rec) * Σ log(N_{k+1}/N_k)`（`N=L+J+M+F`；从低密度恢复到阈值期间统计）
  - **可选更硬核**：随机入侵增长率 `Lambda_inv`（在“七鳃鳗稀有、宿主近边界稳态”处线性化，估计最大 Lyapunov 指数；用于给出 `Lambda_inv>0` 的可持续判据）
  - **准灭绝风险**：`P(min_t N(t) < N_q)`（跨多次随机环境路径的比例）
  - **恢复时间分布**：从 `N_low` 到 `N_target` 的时间分布（中位数/分位数）
  - **生态代价同步报告**：同一批实验同时给 `P(H<H_safe)`，避免“七鳃鳗越强越好”的单目标偏差
- 校准/对照锚点（建议写入“模型校准”段）：可用实证论文给出的 male% 作为目标值来反推 `K_u`/`gamma`/`tau` 的合理范围（详见 `09_paper_notes_0126_1333.md`），例如：
  - 3 年后变态：低生产力环境约 78% male，高生产力环境约 56% male（与赛题锚点一致）
  - 回捕总体：lentic 约 79% male，stream 约 66% male；同一系统 at-large 约 59% male

### 2.2 繁殖效率与性别结构代价（Reproductive constraints）

- 平均受精成功率：`mean_phi = mean(phi(M,F))`
- “配对受限的年份占比”：`P(phi < phi0)`

### 2.3 遗传/有效繁殖规模代理（高级但易写）

给出有效种群大小的经典代理：

```
N_e = 4*M*F / (M+F)
```

解释：雄性过多或雌性过多都会降低 `N_e`（遗传漂变风险上升）。这能把“性别比偏离 1:1 的代价”说得更科学。

### 2.4 bet-hedging 的“策略选择”表达（论文加分口径）

为了把 `S_var` 写成“适应策略”，而不是一个固定函数，建议在随机环境下对 `S_var(θ)` 做一个小规模扫描（参数越少越好）：

- `θ = (gamma, window_length)`（或用 `gamma` + 延迟 `tau` 代表“响应强/弱”）
- 环境用两态马尔可夫（`p_LH, p_HL` 控制自相关强弱；见 `04_equations.md`）

主文只需要报告：存在一个“最优/近最优参数区间”可显著降低准灭绝风险、且不显著加剧宿主崩盘风险。细节扫描曲线可压缩进一张多子图（见 `11_bet_hedging_module.md`）。

本项目默认配置（主文展示用；其余做敏感性）：

- 环境步长 `Δ=1 year`
- 资源对比：基线 `R_H/R_L=5`；敏感性 `{3,10}`
- 环境自相关：`p_LH=p_HL` 取 `{0.5,0.2}`（可选 `{0.1}` 作为极端）
- 主指标：准灭绝概率 `P(min_t N(t) < N_q)`，`N_q=0.05*N_ref`（敏感性 `q∈{0.01,0.10}`；`N_ref` 取 `R=R_bar` 下的常值稳态）

## Q3 稳定性：局部稳定 + 韧性（resilience）

### 3.1 局部稳定（Local stability）

在常值资源 `R=R0` 下：

1. 求平衡点（至少讨论：宿主单独、共存平衡、以及受益者是否可共存）。
2. 对 ODE 线性化，求雅可比矩阵 `Jaco` 的特征值：
   - 最大实部 `<0` 则局部渐近稳定
   - 若出现共轭复根跨过虚轴，可对应 Hopf 分岔（进入振荡）

写作加分点：

- 解释 `gamma`（性别比敏感度）与延迟 `tau` 如何推动/抑制 Hopf：  
  “阈值型更容易引起过冲（overshoot）与振荡，柔性反应更像负反馈控制器。”
- 指出 `tau` 的生物学依据：性腺分化跨越幼体多个年龄/长度窗口、且“years to metamorphosis”与 sex ratio 的关系在实证研究中可观察（见 `09_paper_notes_0126_1333.md`），因此 `tau` 不应被当作纯数学参数。

### 3.2 韧性（Resilience / robustness）

即使不写代码，你也可以先把“韧性指标”定义清楚，后续仿真直接套用：

- Return time：扰动后回到稳态邻域所需时间
- Maximum deviation：扰动后最大偏离幅度 `max |H(t)-H*|`
- Basin proxy：在随机扰动下的“崩溃概率”或“越界次数”

高级但实用：早期预警信号（Early warning signals）

- 方差上升、滞后自相关上升（critical slowing down）  
  可作为讨论段落，显示你对稳定性科学的理解。

## Q4 第三方受益：两类受益者分别给出“入侵阈值”

### 4.1 `B_L`（寄生七鳃鳗）的入侵阈值

在 `B_L≈0` 线性化：

```
dB_L/dt ≈ (eta_L*beta_L*f_J(J*) - d_BL) * B_L
```

入侵条件（等价于 “增长率>0”）：

```
eta_L*beta_L*f_J(J*) > d_BL
```

解释模板：

- `J*` 由性别比策略决定（通过 `F` 和繁殖项影响补充与寄生压力）
- 因而性别比可变会“移动 `B_L` 可生存的参数区域”

### 4.2 `B_H`（感染宿主）的入侵阈值

同样在 `B_H≈0` 线性化：

```
dB_H/dt ≈ (eta_H*beta_H*W(H*,J*) - d_BH) * B_H
```

入侵条件：

```
eta_H*beta_H*W(H*,J*) > d_BH
```

解释模板：

- `W(H*,J*)` 体现“宿主受损程度”（由七鳃鳗寄生强度决定）
- 所以性别比通过改变 `J` 的水平/波动，间接改变机会性寄生者的暴发概率

### 4.3 双受益者并存（Model-3）的讨论抓手

你不需要推复杂解析式，抓住两条间接链即可：

- `B_L↑ → J↓ → W↓ → B_H` 更难入侵
- `B_H↑ → H↓ → J↓ → B_L` 更难维持

用“入侵区/相图”表达最清楚：画出 `(beta_L, beta_H)` 或 `(R0, K_H)` 平面上的共存/排斥区域。

## 参数与不确定性：没有数据也能拿高分的做法

因为题面不给定数据，你需要把“结论稳健”作为主要卖点：

- **范围而非点估计**：给每个关键参数一个合理范围（来自文献或量纲分析），做扫描/敏感性。
- **无量纲化**：把系统压缩成少量关键无量纲组合（例如接触强度、资源尺度、敏感度 `gamma`、延迟强度等）。
- **鲁棒性声明**：结论在多大范围内成立？哪几个参数会改变结论符号？（这往往比给出一个“精确数字”更像科研）

可直接引用的“文献量级”可从 `09_paper_notes_0126_1333.md` 提取到参数表（示例：`egg_to_larva_survival ~ 0.063`；以及宿主作用的 Type-II 饱和形式等）。

## 可选加分模块（不影响主线，但适合冲“Z 奖”）

1) **人类捕捞/控制的门控效应**  
把捕捞写成对成体/寄生期的外部移除率 `u(t)`（见 `04_equations.md`），做两组对照：

- 无捕捞 `u=0` vs 固定捕捞 `u=u0` vs 阈值门控捕捞 `u=u(A)`
- 指标：`mean(H)`、`H_min`、`CV(H)`、七鳃鳗反弹时间（recovery time）

重点讨论一个“反直觉可能”：只削减成体可能让未来幼体密度降低、资源变好，从而性别比更偏雌、补充更强，导致反弹更快（是否发生用敏感性验证）。

2) **个体资源分布导致的 Jensen 效应**  
在不改主系统维度的前提下，引入一个“资源方差”参数 `Var(x_i)`，把 `p_m` 替换为 `p_m_eff=E[p_m(x_i)]`（见 `04_equations.md`）。  
输出建议：在相同 `E[x]` 下扫描 `Var(x_i)`，展示性别比与稳定性边界如何移动（这是很典型的科研式结论）。
