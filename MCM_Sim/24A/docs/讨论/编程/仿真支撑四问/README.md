## 编程/仿真支撑四问（结果归档）

目的：把“代码能回答赛题四问”的证据（表格 + 图片 + 可复现命令）按题目四问整理成可直接写论文的素材包。

目录结构：

- `Q1_生态系统影响/`：可变性别比对更大生态系统（以宿主鱼 H 作为代理变量）的影响
- `Q2_七鳃鳗种群利弊/`：对七鳃鳗自身的利弊（持久性/风险/恢复）
- `Q3_稳定性与韧性/`：局部稳定 + 随机环境韧性（恢复时间）
- `Q4_第三方受益者/`：受益第三方（B_L/B_H）的入侵阈值/随机入侵/全动力学维持

说明：

- 每问目录下都有 `results/figures/` 与 `results/tables/`，用于直接取图/取表。
- 所有结果都可由 `MCM_Sim/24A/run_sim.py` 复现；原始运行目录统一放在 `MCM_Sim/24A/outputs/temp/`。
- 每问的 `README.md` 已按“先纯文本回答、再逐图解释”的结构细化，可直接作为论文写作素材。
- 本目录已更新为“Z 级临界区”参数（避免大量指标全 0/全 1），并补充了更稳健的 bet-hedging 证据：
  - **尾部风险**：`q10_min_N / q10_min_H`（跨随机环境重复的“最坏低谷”10%分位数）
