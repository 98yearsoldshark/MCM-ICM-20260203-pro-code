# data_samples

少量示例数据（xlsx），用于演示 Toolkit 的读取与算法调用。文件体积很小，适合比赛时快速上手。

- `folder6_logistic_credit.xlsx`：二分类小样本（字段含 `X1/X2/X3/Y`）
  - 示例脚本：`MCM_Toolkit_2026/c00_示例_Examples/folder6_logistic_xlsx_demo.py`
- `folder6_grey_gdp.xlsx`：GDP 与产业时间序列（用于灰色关联示例）
  - 示例脚本：`MCM_Toolkit_2026/c00_示例_Examples/folder6_grey_relational_xlsx_demo.py`
- `folder6_grey_mines.xlsx`：矿井指标与理想对象（用于灰色关联示例）
  - 示例脚本：`MCM_Toolkit_2026/c00_示例_Examples/folder6_grey_relational_xlsx_demo.py`
- `folder5_curve_fitting_growth.xlsx`：简单增长序列（字段含 `x/y`）
  - 示例脚本：`MCM_Toolkit_2026/c00_示例_Examples/folder5_curve_fitting_xlsx_demo.py`
