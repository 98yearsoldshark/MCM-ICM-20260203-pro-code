# Curation Policy（筛选与取舍说明）

本文件用于“结项可追溯”：说明从原始资料目录 `2/4/5/6/7` 提炼到 `MCM_Toolkit_2026` 时，哪些内容被保留、哪些内容被忽略，以及忽略的理由。

> 结论：**重复 / 低质 / 基础教学** 类型内容被主动忽略；其余与建模竞赛直接相关、可运行复用的算法与模板被纳入并统一接口。

## 1) 我们保留什么（纳入 Toolkit）

- **数学模型/算法实现**：例如综合评价、预测预报、优化算法、图论、统计检验、微分方程、常见 ML 模型等。
- **可复用的工程模板**：如 Excel/CSV 读取、数据清洗、特征工程、评估与调参等。
- **可运行的 Demo**：每个算法脚本均提供 `solve(data, params)` + `__main__` 示例，做到“复制即可跑通”。
- **必要的理论要点（文本化）**：将 PPT/DOCX/PDF 中的关键公式/适用场景/参数建议提炼为 Markdown 或代码顶部中文注释（不保留难读格式）。

## 2) 我们忽略什么（不纳入 Toolkit）

### 2.1 重复内容

- 同一算法在多处目录出现、或同一目录存在大量 `(1)` 复制版、或仅文件名不同但内容一致。
- 处理方式：**只保留一个最佳实现**（更鲁棒、依赖更少、注释更全、接口更统一），并在索引文件中建立“来源映射”。
  - 目录 2/4/5/6 的映射索引：`folder2_index.md`、`folder4_index.md`、`folder5_index.md`、`folder6_index.md`

### 2.2 低质量内容

典型特征：

- 变量命名混乱、逻辑不完整、缺少输入输出定义、不可复现、强依赖硬编码路径/GUI/联网下载数据。
- 与竞赛实战无关的碎片代码（只展示某个函数 API、或只用于课堂演示）。

处理方式：

- 不直接复制原脚本；若算法本身有价值，则重写为可运行的 Python 版本并加注释。

### 2.3 基础教学内容

例如：

- Python 基础语法、列表/字典/循环等入门讲义
- “安装软件/IDE 使用教程”等非算法资料

处理方式：不纳入 Toolkit（目标用户具备开发基础，只保留算法/模型相关内容）。

## 3) 取舍原则（当发生冲突时）

- **可运行 > 完全复刻**：优先保证离线可运行与接口统一，不追求逐字逐段复刻原文。
- **依赖更少 > 依赖更全**：优先 `numpy/pandas/scipy/sklearn/statsmodels`；重依赖作为可选项放入 `requirements_optional.txt`。
- **可复用 > 单题脚本**：更倾向抽象成通用模块（输入为数组/DataFrame/字典），而不是只能跑某个特定数据文件。

## 4) 已知边界（不属于“缺失”）

若你把“无缺失”定义为“原资料每个文件都被完整转写/收录”，那本项目并不这样做（且不建议这样做），因为会显著增加体积与噪声。

本项目的“无缺失”定义为：

- 对建模竞赛**高频/关键**算法与模板：Toolkit 内有可运行实现；
- 对**少见/进阶**但资料中明确出现的算法：已补齐（见 `advanced_algorithms.md`）；
- 其余内容属于“重复/低质/基础教学/长尾”，按策略忽略。
